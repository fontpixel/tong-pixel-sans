## 背景

Tong Pixel Sans 是 14 像素泛中日韩点阵字体。汉字、假名、谚文、全角符号的墨迹在 13×13 格内，笔画 1 像素；页上每个字右侧的小图是该地区思源黑体，作写法参考。西文：14 Small 字格 14 行（第 11–13 行为降部），14 Large 字格 18 行（第 14–17 行为降部），页上红线是基线。这些字形大多由 AI 修过，还没经用户审核。

## 只列明显的错误

逐页、逐字**实际查看**（detail=original）。只列确定是错的，宁缺毋滥；风格偏好、可改可不改的不列。问题类型只能是：{TYPES}。

- 断笔：本该相连的笔画断开（参考里连着，点阵里断了）。
- 多余黑块：笔画密处糊成 2×2 以上的实心黑块，或明显多出的孤立黑点。
- 不对称：参考左右对称的字（如 木 本 口 A H O）点阵明显不对称。
- 部件间距：左右部件之间空了 2 列以上，或部件互相压住。
- 越界：墨迹贴到或超出格子外，汉字没放在 13×13 内。
- 写法错误：笔画数、部件、点的方向等与该地区参考写法不同（注意简、繁、日、韩写法本来不同，以本字右侧的参考为准）。
- 同族不一致：同一页或相邻页里同一部件、同一字母家族写法明显不同（写出对照的字）。
- 离开基线：西文字母主体没坐在基线上（降部字母 g j p q y 除外）。
- 其他：以上都不是但确定有错（说明清楚）。

## 输出

写 `KIT/results/BATCH.tsv`（UTF-8，制表符分隔），第一行是表头 `id	type	description`，每个问题一行：

```
id	type	description
U+5B57.SC	断笔	子的横钩在第 6 行断开
U+0067.PR-L	同族不一致	g 的下圈与 ĝ ğ 写法不同
```

- `id` 抄 pages.tsv 里的 ID；`type` 只用上面的类型；`description` 一句话，不超过 60 字，写清在哪里。
- 一个字有几个问题就写几行。没有问题的字不写。
- 全部页看完后，最后加一行 `# done 页数`（如 `# done 10`）。没有这一行就算没做完。

不修改 KIT 以外的任何文件（尤其是仓库的 glyphs/），不读其他批次的结果，不浏览网络，不使用图像生成模型。

最终只汇报一行：`batch=BATCH; pages=N; issues=M; result=路径`。
