# 修字编辑器

```bash
python3 tools/editor/server.py            # 然后打开 http://127.0.0.1:8791/
python3 tools/editor/server.py --port 8800
```

要显示参考轮廓，先在仓库里建一个虚拟环境（`.venv/` 不入库），再用它启动：

```bash
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt   # 只需一次
.venv/bin/python tools/editor/server.py
```

编辑器直接读写 `glyphs/` 和 `forms/forms.txt`，保存即改文件；用 `git diff` 查看改动，满意后提交。只接受本机连接。

- 核心功能只需要 Python 3。
- 参考轮廓和相位底稿需要 `tools/requirements.txt` 里的库和 `reference-fonts/` 里的字体，见 [reference-fonts.md](reference-fonts.md)。没有它们时这两项不显示，其他功能照常。
- 地址可以直接指向某个字：`http://127.0.0.1:8791/#glyph=U%2B00E9.HW`。

## 界面

- **左栏**：字形列表。可按字符（`é`、`1`）或码位（`U+00E9.HW`、`00E9`）查找；按状态筛选；每个按钮显示字符、当前像素的 1:1 预览、地区和状态。按清单筛选（`tools/editor/data/lists/` 下每个 `.txt` 是一份清单，一行一个字形 ID，如“常用百字”）；按类别筛选（接下来建议修的简体 / 繁体字、全角标点、西文标点、西文数字、等宽字母、比例字母、有 AI 问题说明、改过、通过、未通过）。别名不在列表中，打开它指向的字形即可。“隐藏字体里用不到的字形”默认勾选：按构建规则，8 个字体都没用到的字形（如思源为半角的 ¤ 的全角版、全宽盲文）不列出；搜索时照常列出。打开这类字时，顶部会说明原因，并链接到字体里实际用的字形。
- **中间**：
  - 参考轮廓：汉字取该地区思源黑体 w400；西文取底稿所用字体与字号。
  - AI 原稿：只在像素改过时显示。
  - 上次提交：git 中最后一次提交的版本。还没有 git 提交时显示“编辑器启动时”：编辑器服务启动那一刻的版本，重启服务就会重置。
  - 当前 1:1 与 4× 预览，以及像素网格。
- **右栏**：同码位其他字形、可复用部件、修改说明、历史版本（git 提交）。

## 画字

- 点按或拖动画点；右键拖动擦除；Shift 拖动或“框选”工具框选。
- 方向键移动选区，Alt + 方向键移动整字；Ctrl+C / Ctrl+V 复制粘贴选区（可跨字）；Delete 清空选区。
- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，Ctrl+S 保存。
- 橙框标出相对“上次提交”的改动；红线是西文基线（第 11 行起为降部）。
- 比例字（`adv=auto`）有“左 +1 / 左 −1 / 右 +1 / 右 −1”宽度按钮，最宽 16 像素；删列时该列必须为空白。构建时步进 = 墨迹宽 + 1。
- “恢复到上次提交”（没有 git 时为“恢复到编辑器启动时”）、“载入 AI 原稿”“把所选历史版本载入编辑区”都只载入编辑区，保存后才生效，可撤销。
- **载入相位底稿**（phase-searched draft）：用参考字体实时重新点阵化，作为重修的起点，不存盘。渲染与 WorkBench 相同（FreeType 单色、关闭 stem darkening、wght 320），另把轮廓横移 k/16 像素（k = 0–15，k = 0 就是 WorkBench 原样），按左右对称、多余 2×2 黑块、断笔和偏离原轮廓的程度打分，取最好的一种。
  - 汉字等地区字形：该地区思源黑体，字面 14×13（“囗”全包围字和“口”为 13×13），放不下依次缩小。
  - 西文、半角假名、泰文、阿拉伯文：该字原底稿所用字体，在基线上；字号自动选择（等宽墨迹不超过 6 列；比例西文墨迹从第 0 列起、右留 1 列）。
  - 底稿会去掉已关联形态的黑点时拒绝载入，需先解除关联。几何字符没有相位底稿。
  - 需要 `tools/requirements.txt` 里的 freetype-py、numpy、fontTools 和 `reference-fonts/`。代码在 `tools/editor/draft.py`，移植自 `archive/tong-ext-v5/scripts/phase.py`、`varraster.py`；与当年存下的底稿抽样 300 字比对，298 字逐像素相同，另 2 字是当年退回小字面时没做相位搜索。
- “全部清空”会先确认，然后解除本字全部部件关联（立即保存），再清空像素（未保存，可撤销）。

## 保存与审核

- **保存修改**：写入文件，状态变为 `edited`（像素没变则不变）。
- **审核通过**：写入文件，状态变为 `approved`。修改已通过的字后需要重新审核。
- 修改说明写进字形块的 `# 人工:` 行。
- 另一个页面或外部程序（git、文本编辑器、脚本）改了同一个字时，保存会被拒绝并提示重新载入，不会覆盖。
- 切换到别的字时，未保存的修改作为草稿留在页面里；关闭页面前请保存。

## 同码位其他字形

列出同一码位的其他地区版本或 HW / PR 版本，以及与之共用字形的地区。

- “打开”：跳到该字。
- “完全复制过来”：用它的全部像素和部件关联替换本字（字格大小须相同；比例字可以从等宽版复制，墨迹靠左、右留一列）。结果待审核。
- “改为本字的别名”：只在它与本字像素、度量完全相同时出现。删去它自己的一份（状态、说明、关联部件；AI 版先存入 `history/ai-originals`），改为共用本字形。
- 共用本字形的地区（别名）也列在这里，“拆开别名”给它一份本字形的副本（像素、度量、说明，部件槽位对得上的关联），之后可以单独修改。本字已通过或改过时，副本的状态是“改过”（这个地区还没审核）；否则沿用本字的状态。

## 可复用部件

汉字按 IDS 结构列出每个部件；西文字母列出基字和每个变音符。每个部件下列出库中该部件的形态，排序依次是：本字已关联的、同码位其他字形在用的、同地区的、与本字吻合度高的。

- **关联并应用**：把形态的黑点放进本字并建立关联。替换已有关联时，只移除原形态的黑点。可以先点“预览”。
- **可移动形态**（西文）：先在网格上框选位置，形态放进框里最吻合处；不框选时，基字放在完全吻合处，变音符对准基字以外的黑点，或放在基字上 / 下方空一行处。已关联的可以用“本字中移动 ← → ↑ ↓”单独挪动，只影响本字。
- **解除关联**：像素不变，只去掉关联。没有字再用的形态会从库中删除。
- **新增形态**：在独立编辑框里画，保存后关联到本字。
- **编辑 / 重命名**：修改形态后，所有关联字在各自位置同步更新，这些字的状态变为 `edited`（像素有变化时），需要重新审核；只改名不影响字形。可移动形态要在用到它的字里编辑。
- 网格上绿色角标是受形态保护的黑点：不能在单字里删除；左键点它定位到所属形态，右键直接编辑该形态。
- 跨地区使用部件是允许的；如果思源黑体中该部件在两个地区写法不同，卡片上会有提示。

## 接下来建议修的字

筛选“接下来建议修：简体 / 繁体”按优先顺序列出还没通过的字。排序方法（`tools/editor/rank_representative.py`）：按 BabelStone IDS 把每个字拆成部件（区分地区和位置，如 SC 氵·左；简繁写法相同的部件算一个），数出每个部件被多少字用到；然后逐个挑选，每次挑能带来最多“还没有通过写法、又被很多字用到”的部件的字，常用字（简体《现代汉语常用字表》3500、繁体常用国字 4808）优先。部件已出现在某个通过字里就算有了。

修好并通过这些字，最常用的部件就都有了人工确认的写法，AI 总结经验和下一轮修字时可以复用。已通过的字自动移出清单；通过了一批之后重新运行，可以得到下一轮：

```bash
python3 tools/editor/rank_representative.py     # 约 1 分钟，写 tools/editor/data/representative.json
```

打开清单里的字时，顶部显示它的名次和带来的部件。

## 自动关联部件

编辑器里画字、审核时不一定顺手关联部件。定期运行：

```bash
.venv/bin/python tools/editor/auto_link.py --dry-run   # 先看报告 reports/auto-link.md
.venv/bin/python tools/editor/auto_link.py             # 默认处理状态为 approved、edited 的字
```

按 BabelStone IDS 把每个简 / 繁 / 日字形拆成部件（`tools/editor/segment.py`，ids-mask-v1）：部件的黑点都取自这个字自己的黑点，三轮拆分，从拆得清楚的字里学习各部件的常见大小和形状。只给指定状态的字、还没有关联的部件位置建立关联；已有关联保留，外层部件已关联时不再关联其内部部件；黑点和坐标完全相同的形态直接复用。任何一处关联会改变像素就整体中止。像素和审核状态都不变。

已通过字的部件会作为“已通过范例”推荐给 AI 修字，所以通过一批字之后最好运行一次。

注意：新结构不记录“手动解除过的形态”，空着的部件位置可能被重新关联；不满意就在编辑器里解除。

## 其他

- **预览通过字 / 预览所有字**：按地区连续排出字形，1:1 和放大各一份；点字跳回编辑。
- **所有部件**：浏览、搜索全部形态，查看每个形态被哪些字关联。

## 开发备注

- `tools/editor/store.py`：读写文本源文件、状态、git 历史、AI 原稿存档。
- `tools/editor/forms.py`：部件关联、形态编辑与同步（逻辑来自旧编辑器 `archive/tong-review-v1/shapes.py`）。
- `tools/editor/structure.py`、`vendor/babelstone/`：BabelStone IDS 结构查询。
- `tools/editor/reference.py`：参考轮廓；`tools/editor/draft.py`：相位底稿；`tools/editor/rank_representative.py`：建议修字清单（移植自 `archive/tong-review-v1/rank_representative.py`）。
- `tools/editor/web/`：页面（无构建步骤的原生 JavaScript）。
- 测试：`python3 tools/editor/test_store.py`（只用临时目录里的合成数据）。
