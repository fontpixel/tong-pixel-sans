# 西文连带更新工具

改了西文基字或变音符后，用 `tools/western/` 的脚本把改动带到同一字族的其他字母。脚本读写的源文件和编辑器相同，改动的字状态变为 `derived`，并在 `# 人工:` 说明里写明来由。报告写到仓库根目录的 `reports/`（不入库）。报告里的对比图需要 Pillow 和参考字体 `reference-fonts/SourceHanSansSC-VF.otf`，所以用 `.venv` 里的 Python 运行（建法见 [editor.md](editor.md)）。

先加 `--dry-run` 看报告，确认后再去掉它执行；执行后用 `git diff` 检查。

## 先看部件关联

大多数西文字母已经关联了可移动形态（基字、变音符）。**改已关联的形态本身**（编辑器中“编辑”形态），所有关联字会立即同步，不需要这些脚本。脚本只处理没有关联的字，或你直接在某个字里改了像素的情况。

判断一个字由谁画的：`approved` / `edited` = 你，`derived` = 脚本，`ai` = AI 原稿。脚本不改你画过或通过的字（`--include` / `--force` 指定的除外）。

## 标准顺序

```bash
.venv/bin/python tools/western/propagate_family.py --group HW --dry-run   # 1. 等宽版：基字和变音符带到同族字母
.venv/bin/python tools/western/sync_pr.py --dry-run                       # 2. 你改过的等宽字复制到比例版
.venv/bin/python tools/western/derive_pr.py --dry-run                     # 3. 比例版变体 = 比例版基字 + 等宽版变音符
.venv/bin/python tools/western/link_western.py --dry-run                  # 4. 给还没关联的字建立可移动形态关联
```

### 1. `propagate_family.py --group HW`

- **基字**：对每个基本字母，在同族字母（À Á Â … 之于 A）里找到 AI 原稿的基字位置，换成当前的基字；变音符随基字移动（上方符号跟基字顶边，下方符号跟底边，都按中心对齐）。AI 为放下声调把大写压扁过的，按同样的行压扁。
- **变音符**：你在某个字母上改过的变音符（如 é 的尖音符、Ç 的尾巴、Ę 的小钩），套用到同一大小写、同一文字的单变音符字母。拉脱维亚逗号形（Ģ Ķ Ļ Ņ Ŗ）和希腊 tonos 除外；叠加变音符只在原写法相同时替换。两个字母上同一变音符改得不一样时，不猜，列入报告的 `mark_conflicts`。
- 找不到基字、超出字格、变音符会贴到基字的，列入报告的 `manual`。
- `--include 字符`：连你改过的字也重建。
- `--group PR` 是早期做法，已被第 3 步取代，平时不要用。

### 2. `sync_pr.py`

- 把你改过的等宽字（`.HW`）复制到比例版（`.PR`）：裁到墨迹，右边留 1 列。
- 你直接改过的比例字保留（`--force 字符` 可强制覆盖）。
- 宽字母 W M m w Æ Œ æ œ 及其变体不复制，比例版单独画；`--restore-wide` 把被误复制的恢复成 AI 原稿。
- 带变音符的字母默认不复制（由第 3 步生成），除非是你亲手在等宽版画的；`--variants 字符` 可强制复制。

### 3. `derive_pr.py`

- 比例版带变音符的字母 = 比例版自己的基字 + 等宽版同一个字的变音符：上下间隔相同，按基字中心对齐，等宽版为放声调压扁的行同样压扁，最后裁到墨迹、右留 1 列。
- 你画过或通过的比例字，以及你亲手画过等宽版的字（第 2 步已复制）不碰。
- `--include 字符`：连你改过的字也重建。

### 4. `link_western.py`

- 每个基本字母每版（等宽、比例）一个基字形态（“A · 等宽”“A · 比例”）；为放声调压扁的另成一个（“A · 等宽 · 压扁（去掉第 N 行）”）。与拉丁字母完全同形的希腊、西里尔字母共用拉丁的形态。
- 每种变音符按大小写和文字（拉丁 / 西里尔、希腊）各一个形态，两版共用；标准写法取出现最多的写法，两种写法一样多时列为冲突。
- 钩、横、斜线等属于字母本身的部分不做形态，只关联基字。
- **只在像素完全吻合时关联，关联不改任何像素和状态。** 其余写进 `reports/link-western.md` 和 `.png`，按你 / 程序 / AI 画的分组，附基本字母对照，供人工处理。
- 可以重复运行：同名同像素的形态会复用，已关联的位置保留。
